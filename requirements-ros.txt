# 系统依赖（apt / ROS 2 Humble）—— 给新同事用的清单
#
# 目标环境：Ubuntu 22.04 (jammy) + ROS 2 Humble + Gazebo Classic 11
#
# 一键安装（-y 之前建议先 dry-run 看一眼）：
#   grep -vE '^\s*(#|$)' requirements-ros.txt | xargs sudo apt install -y
#
# 更省事的等价做法（由各 package.xml 自动推导，推荐）：
#   source /opt/ros/humble/setup.bash
#   sudo rosdep init && rosdep update     # 只需第一次
#   rosdep install --from-paths src --ignore-src -r -y
#
# 下面按用途分组；带 [可选] 的可以最后再装。
